Library Management System

Project Description

The Library Management System is a Python-based application developed to manage books, students, book issuing, and returns efficiently.

This project provides a simple web interface that helps users manage library operations.

Technologies Used

- Python
- SQLite Database
- Gradio
- Google Colab

Features

- Add new books
- View all books
- Search books
- Register students
- View student details
- Issue books to students
- Return books
- Calculate fines
- View transaction history
- Dashboard to monitor library activities

How to Run the Project

1. Open the project notebook in Google Colab.
2. Run the code cells in the correct order.
3. Wait for the Gradio application to launch.
4. Open the generated Gradio public link.
5. Use the application to manage books and student records.

Important Note

The application currently runs through Google Colab using a temporary Gradio public link. The Colab runtime must remain active while using the application.
